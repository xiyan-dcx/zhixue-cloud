# 智学云前端

在本目录执行：

```sh
npm install
npm run dev
```

打开终端输出的 Local 地址。配置端口为 5173，端口被占用时 Vite 会使用其他可用端口。

类型检查与生产构建：

```sh
npm run build
```

## 当前页面

- `/login`：登录页，账号和密码默认留空。
- `/`：按角色进入首页，管理员、讲师进入数据看板，学员进入我的课程。
- `/my-courses`：学员个人学习清单，支持阅读章节和移出课程。
- `/profile`：个人中心，修改昵称、头像和密码。
- `/dashboard`：数据看板，仅管理员、讲师可访问。
- `/course`：课程管理。
- `/student`：学员管理。
- `/order`：订单管理。
- `/system/user`：用户管理。

路由入口为 `src/router/index.ts`，页面存放在 `src/views`。具体菜单及业务操作受账号权限控制。

## 演示账号

以下为原登录页提供的演示账号，需在后端数据库中已初始化对应用户后使用；此表不会自动创建账号或重置密码。

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | `admin` | `123456` |
| 讲师 | `teacher01` | `123456` |
| 学员 | `student01` | `123456` |

登录时请手动输入。学员账号不显示数据看板菜单，也不能访问看板页面或接口。

学员在课程列表点击「购买课程」，确认模拟支付后加入我的课程；弹窗会显示价格并明确提示不会真实扣款。免费课程可直接加入。已开通课程显示「已开通 · 恢复清单」，不会再进入支付弹窗；后端拒绝重复购买。移出后可恢复清单，不创建新订单。新账号清单默认为空，模拟订单不会计入真实收入。

个人中心只能修改当前账号的昵称、头像和密码，账号及角色只读。上传头像限 PNG/JPEG、2MB、2048×2048；修改密码需要原密码，新密码8–64字符且UTF-8编码不超过72字节，成功后所有旧令牌失效。

开发代理在 `vite.config.ts` 中配置：`/api` 转发到 `http://localhost:8080` 并去掉 `/api` 前缀，`/uploads` 保留路径转发到同一后端。
